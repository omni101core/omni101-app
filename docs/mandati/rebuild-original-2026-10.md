# 5. CREATIVE MOTION SYSTEM — IMPLEMENTAZIONE DECISA

## 5.1 HOME HERO — EXPANDING REEL ORBIT

Reference:

https://www.avivashishta.com/blog/prompt-reel-ring-loader-that-opens-into-a-3d-carousel-hero

### Comportamento

Crea un sistema di 12–16 card contenenti progetti e capacità OMNI101.

Inizialmente le card sono disposte intorno a un anello tridimensionale compatto.

Durante la prima entrata, l'anello si espande e diventa un carousel immersivo.

Le card contengono:

- Anteprime di web app.
- Dashboard.
- E-commerce.
- Creative AI.
- Avatar.
- Automazioni.
- Software su misura.
- Video pubblicitari.

Il visitatore può esplorarle trascinando o usando le frecce.

Le card sono link reali.

### Implementazione

React + Motion + CSS transforms 3D.

Non usare Three.js per un carousel di semplici piani DOM se CSS 3D è sufficiente.

Usa valori condivisi per formazione, espansione e rotazione.

Supporta:

- Mouse drag.
- Touch swipe.
- Frecce tastiera.
- Bottoni precedenti/successivi.
- Pausa.
- Reduced motion.
- Skip animation.
- Asset readiness.

### Regola UX

Non mostrare ogni volta una lunga animazione di caricamento.

L'introduzione deve essere facoltativa e rapidamente saltabile.

Il contenuto principale rimane comprensibile senza JavaScript o WebGL.

Il loader deve misurare asset realmente caricati, non progressi inventati.

## 5.2 SIGNATURE 3D — OMNI PORTAL

Realizza un secondo elemento visuale originale con React Three Fiber.

Non sovraccaricare il hero con due scene 3D contemporanee.

OMNI PORTAL è un sistema modulare che simboleggia trasformazione e connessione.

Deve avere stati:

- Idle.
- Explore.
- Build.
- Automate.
- Create.
- Grow.
- Project.

Usa Three.js, R3F, Drei e GSAP.

Carica la scena quando appropriato.

Evita postprocessing costoso non necessario.

Supporta fallback statico.

L'oggetto deve poter essere utilizzato nelle transizioni e nelle pagine servizio, mantenendo coerenza.

## 5.3 SCROLL CHOREOGRAPHY

Reference:

https://www.avivashishta.com/blog/prompt-premium-property-site-scroll-choreography-replit

Implementa una grammatica di scrolling con:

- Pinned hero limitato.
- Text reveal.
- Word-spacing transformation.
- Clip-path reveals.
- Horizontal track.
- Depth shift.
- Scala e maschere.
- Rewind naturale durante lo scroll inverso.

Ogni sezione deve avere un linguaggio coerente ma non necessariamente lo stesso effetto.

Non applicare pin multipli che interferiscono fra loro.

Non bloccare lo scrolling nativo.

Usa ScrollTrigger soltanto nelle sezioni che richiedono coordinamento temporale.
